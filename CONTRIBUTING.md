# Collaboration Guide

Thanks for your interest in collaborating.

This repository is my main GitHub profile repository, so contributions should improve the accuracy, clarity, or presentation of my public profile and related documentation.

## Good Contribution Areas

Useful contributions include:

- Fixing typos, broken links, layout issues, or rendering problems.
- Improving accessibility for SVGs, badges, images, and Markdown content.
- Suggesting clearer wording for project descriptions.
- Reporting broken external assets or third-party README widgets.
- Small improvements to profile documentation.

For collaboration on AI-integrated apps, RAG systems, computer vision, NLP, or open source projects, please open an issue or contact me through the links in the README.

## Before Opening a Pull Request

Please keep changes focused and easy to review.

- Do not rewrite the full README without prior discussion.
- Do not replace the profile style or visual theme without opening an issue first.
- Keep SVG changes and Markdown changes scoped to the specific improvement.
- Avoid adding heavy external dependencies or new third-party services without a clear reason.
- Do not include secrets, private information, or confidential project details.

## Pull Request Expectations

A good pull request should include:

- A short explanation of what changed.
- Screenshots or rendered previews for visual changes when possible.
- A note about any external services, images, badges, or generated assets added.
- A clear reason for the change.

## Issues

When opening an issue, include:

- What you expected to happen.
- What actually happened.
- The browser, device, or GitHub surface where you saw the problem, if it's visual.
- Links or screenshots when they help explain it.

## Security Reports

Please do not report security issues publicly. Use the process in `SECURITY.md`.
